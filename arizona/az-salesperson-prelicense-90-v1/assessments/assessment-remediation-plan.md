# Arizona Salesperson Pre-License 90h — Assessment, Remediation, and Final Plan

Each instructional unit has an applied task and scored check; each module has a versioned quiz. An incorrect response assigns an alternate explanation, a different scenario, and a parallel scored item. Repeated objective failures create an instructor-support record without silently altering progress.

Final configuration: one comprehensive randomized form per attempt; form length to be set by the approved assessment blueprint; bank ratio at least 2:1; passing score 75%; lockdown delivery; final time excluded from instructional hours. Proctoring and device method must satisfy the final ADRE-approved delivery configuration. The secure bank remains non-public and requires legal, subject-matter, editorial, duplication, bias/accessibility, security, and psychometric review before filing or production.

## Unit assessment record

Every attempt stores course version, objective ID, item version, response, score, timestamp, identity/session evidence, IP metadata, remediation assignment and outcome. Students never see the key before submission. A failed 75% unit quiz prevents progression, assigns an alternate explanation and scenario, and requires a parallel item. Repeated difficulty creates an instructor-support flag without silently changing the student's regulated record.
