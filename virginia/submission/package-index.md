## DPOR packaging rules captured from the current application

- Submit only electronically to **reschool@dpor.virginia.gov**.
- Use one combined PDF without security settings.
- Put attachments in numerical order.
- Include a section header sheet for every attachment even when no documentation follows.
- Bookmark the PDF by section.
- Keep the file size as small as practical.
- Use the provider name and document title in the email subject.
- Submit by the current Education Committee deadline.
- Do not substantially alter approved content or time allocations without determining whether revised Board approval is required.
