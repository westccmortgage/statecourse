# Pennsylvania Submission Package Index

**Development package — no regulatory submission, approval, enrollment or credit claim.**

## Provider layer

1. Initial provider application and $120 fee record.
2. Owner application exhibits.
3. Director application exhibits.
4. $10,000 surety bond.
5. Entity and facility exhibits.
6. Enrollment agreement, refund policy and transcript sample.
7. Custodian-of-records designation.

## Instructor layer

1. Instructor application and $20 fee record.
2. Director qualification certification.
3. Degree or directly related three-year experience evidence.
4. Course assignment for both Fundamentals and Practice as applicable.
5. Ongoing education/experience record.

## Distance delivery layer

1. Method-delivery certification/approval evidence and ARELLO/IDECC number.
2. System description: active time, inactivity exclusion, interaction, mastery, remediation, authentication and audit trail.
3. Commission reviewer URL, credentials and all-course bypass isolated from student credit.
4. Proctor identity, environment, integrity and incident procedures.
