# Non-ARELLO Distance-Delivery Equivalence

StateCourse does not rely on ARELLO certification for this Michigan application. It requests approval of an equivalent delivery system under R 339.22157(4).

| Current rule | Evidence |
| --- | --- |
| R 339.22157(2)(a) — all R 339.22141 application requirements | Official application, course package, attachments, programme/person records |
| (b) — individual computer/interactive modules | Ten independently addressable four-hour modules |
| (c) — at least one objective per module covering the whole course | Objectives in every module; union mapped in `../module-map.md` |
| (d) — structured learning method for each objective | Objectives, six instructional sections/checkpoints, examples, practice, applied work, engagement assessment |
| (e) — assessment during each module | Instructor-reviewed written memorandum, one applied confirmation item, and five-item engagement assessment inside each module |
| (f) — remediation repeating the module until understood | Memo feedback/revision, applied-confirmation review, failed mastery state, alternate explanation and separate five-item set, completion refusal, instructor escalation |
| R 339.22157(5) — hardware/software remedy | `hardware-software-plan.md` |

## Reviewer evidence

The reviewer receives:

- a read-only course account covering all ten modules;
- the module/objective/hours map;
- a demonstration of incomplete, failed, remediation, and completed states;
- assessment manifests and secure answer-key access by a separate channel;
- time, identity, attestation, completion, and certificate-gate examples; and
- the incident/correction procedure.

ARELLO may be pursued separately for jurisdictions that require it. Its absence does not reduce or defer any element of the Michigan equivalence showing.
