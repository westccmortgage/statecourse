## The approval path

Michigan is a two-regulator filing. PSS licensure is required; the exact MiPSS application category and initial temporary-permit treatment await written confirmation.

1. **LEO Post Secondary Schools (PSS)** provides the required school authorization and program approval. If PSS confirms the Proprietary School route, the initial filing is treated as a temporary-permit application leading to a regular licence after satisfactory operation. A nonaccredited proprietary-school licence is renewable and valid for no more than one year.
2. **LARA Bureau of Professional Licensing (BPL)** approves the 40-hour real-estate prelicensure course and every instructor.
3. StateCourse returns the BPL approval evidence to MiPSS if PSS requires it as the secondary-agency approval upload.
4. Enrollment stays disabled until both tracks are approved and the production identity, attestation, reporting, contract, refund, and certificate gates pass.

The BPL form asks for a Michigan proprietary-school number while MiPSS asks for secondary-agency approval. The prefiling questions request the agencies' exact sequencing. No package waits idle for the answer: both are assembled in parallel.
