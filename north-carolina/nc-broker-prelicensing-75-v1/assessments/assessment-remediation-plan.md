# North Carolina Broker Prelicensing 75h — Assessment, Remediation, and Final Plan

Each instructional unit has an applied task and scored check; each module has a versioned quiz. An incorrect response assigns an alternate explanation, a different scenario, and a parallel scored item. Repeated objective failures create an instructor-support record without silently altering progress.

Verified final controls are: comprehensive coverage, three course hours, closed-book administration, proctoring, identity/security protection for distance delivery, and a 75 percent passing score. Public sources reviewed for this build do not fix a universal item count, bank ratio, retake count, retest interval, or remote-proctor vendor. Those values remain unset pending NCREC confirmation. No production-ready final bank exists yet.
