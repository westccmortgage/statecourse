# North Carolina Broker Prelicensing 75h — Instructor Approval and Assignment File

Assignment: **Unassigned — production release gate**

The file must contain the current NCREC instructor application and approval, approved course scope, instructor number, effective/expiration dates, résumé/CV, active non-provisional North Carolina broker license, active-status education evidence, at least 60 accredited semester hours, the qualifying recent experience pathway, criminal/occupational-license disclosures, passing instructor-approval examination, New Instructor Seminar completed within the prior six months, successful 15-minute teaching block, annual six-hour instructor-development evidence, and course assignment.

No owner, contractor, author, or reviewer is deemed qualified without a current NCREC approval record. Assignment remains a production release gate.
