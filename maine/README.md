## Release gate

Nothing in this directory authorizes advertising, enrollment, course delivery for licensure credit, or issuance of a qualifying-education certificate. The release owner must record written Commission approval, approval dates and number, accepted distance-delivery pathway, instructor approval/acceptance, and final provider policies before changing `regulatoryStatus` or `enrollmentEnabled` in `lms-config.json`.
