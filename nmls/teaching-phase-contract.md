## Authority and source integrity

- The private `netlify/functions/_lib/nmls-teaching-transaction.mjs` adapter supplies the authenticated actor, original review, original policy binding/offering and exact private source-loader payload. Browser JSON must not supply any of them. Current binding policy ID/digest, actor/grant ownership, annual-window shape and original content pins must match. No endpoint imports this adapter yet.
- Both existing source loaders hash ordered `JSON.stringify` payload bytes before adding `digest`; the constructor recomputes that exact hash. A changed lesson or shorter allocation under a copied digest is rejected. Do not rebuild the source from JSONB with changed object-key order or silently rehash/relabel a persisted grant. Hashes detect drift, not authorization.
- Runtime IDs/status, non-credit flags, exact sequential completion sets and total completed provisional milliseconds must match the source. Terminal status requires every unit and module with no pending work. Active-unit requirements/actions/time bounds are rechecked against its actual next unit. The common active-unit check also serves existing bookmark validation.
- Remediation additionally requires a sealed failed first form, matching student/original-review/definition, immutable selection IDs, submitted timestamp, exact regraded result and exact reconstructed manifest. Child workflow must still be `remediating`, with no second-form fields and separate valid revisions. A later content-free original receipt does not invalidate an older sealed submission. Child evaluation cannot precede that submission's timestamp.
- The child begins with its own empty runtime. This helper validates loaded state; existing028's start transaction enforces empty initialization. Neither constructor alone proves how a loaded completion state was earned.

Contexts have a process-local `WeakMap` brand and pin full course/runtime/offering snapshots. Copied, deserialized, prototype-derived or subsequently mutated contexts fail; there is no generic `allowContentDigestMismatch` switch. The adapter rebuilds a context after each authoritative load and checks a proposed context before committing. This brand is an internal misuse guard, not a durable signature, client token or database security boundary. A caller controlling trusted server inputs is still trusted.
