# Illinois mandatory portfolio roadmap

Rule 1450.1105(b)-(d) requires an education provider offering pre-license courses to provide the seven courses below. Subsection (e) additionally gates the 30-hour endorsement course and CE core. First commercial product: the 75-hour entry-level Broker package. Anatoliy's personal endorsement education is separate and should come from an already approved provider. This is our build order, not a statutory filing order.

The September 6 audit added the missing official Managing Broker curriculum and a seven-course/165-hour course-level map in `config/illinois/course-portfolio.json`. Detailed subordinate-topic objectives and substantive teaching citations remain incomplete. See `source-foundation-audit.md` for current-law overlays, actual source hashes and remaining gaps.

## Package completion definition

A course is not “built” merely because prose exists. It needs: fixed official sources; page-numbered student text; instructor materials; learning objectives; exact timed outline; activity/assessment bank; required final and answer key where applicable; delivery/identity/attendance records; accessibility review; reference manifest; and a course-application export whose hashes are stable.

The provider form requires separate course applications and fees. Because the simultaneous initial filing of the seven courses plus endorsement is not explicit, obtain written IDFPR Education guidance before paying the optional eighth nonrefundable fee.
