# Washington Real Estate Practices 30h — Instructor Approval and Assignment File

Assignment: **Unassigned — production release gate**

The file must contain the current Washington instructor application/approval or DPOS-qualified staff record, approved subject scope, approval number, effective/expiration dates, résumé/CV, education, licenses, experience, teaching-method evidence, background/disclosure material, renewal evidence, availability/response commitments, and course assignment. No owner, contractor, author, or reviewer is deemed qualified without the applicable state record.
