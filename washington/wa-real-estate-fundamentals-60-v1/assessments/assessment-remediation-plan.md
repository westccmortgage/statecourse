# Washington Real Estate Fundamentals 60h — Assessment, Remediation, and Final Plan

Each instructional unit has an applied task and scored check; each module has a versioned quiz. An incorrect response assigns an alternate explanation, a different scenario, and a parallel scored item. Repeated objective failures create an instructor-support record without silently altering progress.

Final configuration: 1 secure form(s); 180 items/form; bank ratio 1:1; passing score 70%; administration: Secure school examination; no separate proctor mandate identified in WAC 308-124H. The draft bank is non-public and requires legal, subject-matter, editorial, duplication, bias/accessibility, and psychometric review before filing/production.
