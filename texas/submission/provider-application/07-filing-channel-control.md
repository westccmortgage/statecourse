# Filing-channel control — REALM versus “Apply by Mail”

**Current conflict, observed 2026-09-02:**

- TREC's current QE provider page and current QE course page display **Apply by Mail**.
- The form listing names the QE Provider Initial Application effective **09/03/2025**.
- Clicking that application route redirects to the REALM login instead of a PDF.
- TREC's current REALM FAQ says provider and course applications are processed and managed online and supporting documents are uploaded in REALM.

## Decision rule

1. Prepare one channel-neutral packet using the current public instructions and linked checklist.
2. Open the application through the published TREC link while signed into REALM.
3. If the application workflow is available, use REALM and upload the packet there; the current TREC FAQ supports that path.
4. If REALM does not expose the initial QE provider workflow, call TREC Education and Examinations at the contact shown on the official site and ask only: “For the QE Provider Initial Application effective 09/03/2025, should a new applicant submit in REALM or by mail, and how should the original sealed bond be delivered?”
5. Save the answer or portal confirmation with the submission record. Do not use two parallel filings and do not pay twice.

The conflict is an administrative dispatch issue, not a reason to delay the company, financial, bond, agreement or course-package work.
