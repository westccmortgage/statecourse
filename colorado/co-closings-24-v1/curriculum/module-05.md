> > assumptions (FHA, VA and conventional), new loans (FHA, VA and conventional), and a closing involving a

## Learning objectives

1. Work a closing problem end to end on a six-column worksheet and prove that in equals out.
2. Work a cash closing, and say what is absent from it.
3. Work a new loan closing on FHA, VA and conventional terms as given.
4. Work an assumption, and identify what the contract must settle about release.
5. Work an owner carry closing, and identify what the seller has become.
6. Work a multi-family closing with rents, deposits and a partial month.
7. Work three problems from prepared contracts, closing to the contract as written.
8. Identify, in any problem, a charge that is not supported by the contract.

---

## A. How a problem is worked

**The same seven steps every time.**

| Step | What is done |
|---|---|
| **1** | **Read the contract** — price, earnest money and its holder, financing structure, closing and possession dates, every contingency, and every cost allocation |
| **2** | **List every item** the transaction produces, and mark each **contractual** or **non-contractual** |
| **3** | **Compute each proration** — daily rate, days each side, direction by prepaid or in arrears |
| **4** | **Place every item** on the six-column worksheet with the right party and the right sign |
| **5** | **Total each column** and derive **cash from the buyer** and **cash to the seller** |
| **6** | **Prove the money** — everything received equals everything disbursed |
| **7** | **Check against the contract** — nothing on the statement that the contract or a written amendment does not support |

**Step 7 is the Commission's own sentence from Topic III.A.1:** ***"Close to contract or amend contract in
writing."*** A charge the parties agreed to informally is amended in first, or it does not appear.

## C. Problem 1 worked in full — a cash closing

**Every figure given.**

> Price **$395,000**, all cash. Earnest money **$12,000**, held by the brokerage. Compensation **5.5
> percent** of the price, charged to the seller. Seller's existing loan payoff **$147,300**. Title insurance
> premium **$1,720**, seller. Recording: buyer **$180**, seller **$40**. Annual taxes **$3,600**, **payable
> in arrears**; closing **1 July**; **360-day year, 30-day months**, seller charged through the day before
> closing.

**Step 3 — the proration.** Daily **$3,600 ÷ 360 = $10.00**. Seller's days **180** (January–June).
**Seller's share $1,800**, and because the taxes are in arrears it is a **credit to the buyer** and a
**debit to the seller.**

**Steps 4 and 5 — the worksheet.**

| Item | Buyer debit | Buyer credit | Seller debit | Seller credit |
|---|---|---|---|---|
| Purchase price | 395,000.00 | | | 395,000.00 |
| Earnest money | | 12,000.00 | | |
| Existing loan payoff | | | 147,300.00 | |
| Compensation (5.5%) | | | 21,725.00 | |
| Title insurance | | | 1,720.00 | |
| Recording | 180.00 | | 40.00 | |
| Tax proration (arrears) | | 1,800.00 | 1,800.00 | |
| **TOTALS** | **395,180.00** | **13,800.00** | **172,585.00** | **395,000.00** |

> **Cash from the buyer = 395,180.00 − 13,800.00 = $381,380.00**
> **Cash to the seller = 395,000.00 − 172,585.00 = $222,415.00**

**Step 6 — prove it.**

| In | | Out | |
|---|---|---|---|
| Buyer's cash | 381,380.00 | Payoff | 147,300.00 |
| Earnest money | 12,000.00 | Compensation | 21,725.00 |
| | | Title insurance | 1,720.00 |
| | | Recording (180 + 40) | 220.00 |
| | | Seller's proceeds | 222,415.00 |
| **TOTAL** | **393,380.00** | **TOTAL** | **393,380.00** |

**What a cash closing is missing, and why it is problem 1.** No loan proceeds credit, no loan costs, no
prepaid interest, no lender's requirements to satisfy. **Everything left is the transaction itself** — which
is why it is the clearest place to learn the worksheet before the loan lines are added.

## D. Problem 5 worked in full — an assumption

**Every figure given.**

> Price **$362,000**. Earnest money **$8,000**. The buyer **assumes** the seller's existing conventional
> loan; the **principal balance as of closing is $228,450**, and **interest accrued and unpaid to the
> closing date is $604**. Assumption fee **$450**, charged to the buyer. The buyer pays the balance of the
> price in cash. Compensation **6 percent**, seller. Title insurance **$1,610**, seller. Recording: buyer
> **$180**, seller **$40**. Annual taxes **$4,800**, **prepaid by the seller for the calendar year**;
> closing **1 May**; **360-day year, 30-day months**; buyer charged from the closing date.

**The tax proration.** Daily **$4,800 ÷ 360 = $13.3333**. Buyer's days: **240** (May–December).
**Buyer's share = 240 × $13.3333 = $3,200.00** — and because the seller **prepaid**, it is a **debit to the
buyer** and a **credit to the seller.**

**The accrued interest.** The seller used the money and has not paid the interest; the buyer is taking over
the loan and will pay it. So **$604 is a credit to the buyer and a debit to the seller.**

| Item | Buyer debit | Buyer credit | Seller debit | Seller credit |
|---|---|---|---|---|
| Purchase price | 362,000.00 | | | 362,000.00 |
| Earnest money | | 8,000.00 | | |
| Loan assumed | | 228,450.00 | 228,450.00 | |
| Accrued interest on assumed loan | | 604.00 | 604.00 | |
| Assumption fee | 450.00 | | | |
| Compensation (6%) | | | 21,720.00 | |
| Title insurance | | | 1,610.00 | |
| Recording | 180.00 | | 40.00 | |
| Tax proration (prepaid) | 3,200.00 | | | 3,200.00 |
| **TOTALS** | **365,830.00** | **237,054.00** | **252,424.00** | **365,200.00** |

> **Cash from the buyer = 365,830.00 − 237,054.00 = $128,776.00**
> **Cash to the seller = 365,200.00 − 252,424.00 = $112,776.00**

**Prove it.**

| In | | Out | |
|---|---|---|---|
| Buyer's cash | 128,776.00 | Compensation | 21,720.00 |
| Earnest money | 8,000.00 | Title insurance | 1,610.00 |
| | | Recording (180 + 40) | 220.00 |
| | | Assumption fee to lender | 450.00 |
| | | Seller's proceeds | 112,776.00 |
| **TOTAL** | **136,776.00** | **TOTAL** | **136,776.00** |

**Note that the assumed loan never becomes cash.** It appears as a **credit to the buyer and a debit to the
seller** and cancels between them — no money moves, because the debt simply changes hands.

> **What the contract must settle, and what a broker raises before it is signed.**
>
> **Is the seller RELEASED?** Without a **written release from the lender**, the seller may remain liable on
> the note after closing. The alienation (due-on-sale) clause is why the lender is involved at all, and the
> release is a separate document the lender must issue. **A broker ensures the seller understands the
> question and takes it to counsel** — **§§ 12-10-404(1)(c)(V) and 12-10-407(2)(b)(II)** each require
> advising the party to obtain expert advice on material matters beyond the broker's expertise.
>
> **And the contract must state what happens if the lender refuses approval** — the three-part contingency
> test: **what event, by when, what happens if it does not occur.**

## E. Problem 8 worked in full — a multi-family closing

**Every figure given.**

> A **six-unit** building at **$1,375** per unit per month. Price **$1,240,000**. Earnest money **$25,000**.
> New loan **$930,000**; buyer's loan costs **$11,800**. Compensation **5 percent**, seller. Seller's payoff
> **$486,200**. Title insurance **$3,100**, seller. Recording: buyer **$180**, seller **$40**. **June rents
> collected in full by the seller**; **security deposits of $1,375 per unit** are held by the seller's
> managing brokerage. Closing **20 June**; **30-day month**; **buyer charged for the day of closing**.

**Rents.** June rent collected **6 × $1,375 = $8,250**. Daily **$8,250 ÷ 30 = $275.00**. Buyer's days
**11** (20th through 30th). **Buyer's share = 11 × $275.00 = $3,025.00** — **credit to the buyer, debit to
the seller.**

**Security deposits.** **6 × $1,375 = $8,250**, transferred **in full and not prorated** — **credit to the
buyer, debit to the seller.**

| Item | Buyer debit | Buyer credit | Seller debit | Seller credit |
|---|---|---|---|---|
| Purchase price | 1,240,000.00 | | | 1,240,000.00 |
| Earnest money | | 25,000.00 | | |
| New loan proceeds | | 930,000.00 | | |
| Buyer's loan costs | 11,800.00 | | | |
| Existing loan payoff | | | 486,200.00 | |
| Compensation (5%) | | | 62,000.00 | |
| Title insurance | | | 3,100.00 | |
| Recording | 180.00 | | 40.00 | |
| Rent proration (11 days) | | 3,025.00 | 3,025.00 | |
| Security deposits | | 8,250.00 | 8,250.00 | |
| **TOTALS** | **1,251,980.00** | **966,275.00** | **562,615.00** | **1,240,000.00** |

> **Cash from the buyer = 1,251,980.00 − 966,275.00 = $285,705.00**
> **Cash to the seller = 1,240,000.00 − 562,615.00 = $677,385.00**

**Prove it.**

| In | | Out | |
|---|---|---|---|
| Buyer's cash | 285,705.00 | Payoff | 486,200.00 |
| Earnest money | 25,000.00 | Compensation | 62,000.00 |
| New loan proceeds | 930,000.00 | Title insurance | 3,100.00 |
| | | Recording (180 + 40) | 220.00 |
| | | Buyer's loan costs | 11,800.00 |
| | | Seller's proceeds | 677,385.00 |
| **TOTAL** | **1,240,705.00** | **TOTAL** | **1,240,705.00** |

> **The Chapter 5 consequences a multi-family closing produces, all from rules read in full.**
>
> **Rule 5.5** — a firm engaging in property management must hold **rental receipts and security deposits in
> SEPARATE trust or escrow accounts**, a minimum of one for each.
>
> **Rule 5.8.A** — a firm receipting for security deposits **will not deliver them to an owner** without the
> **tenant's written authorization in a lease** or **written notice** telling the tenant **who holds the
> deposit** and **the procedure for requesting its return.**
>
> **Rule 5.8.B** — where management passes to a **new** brokerage firm: **written disclosure to owner and
> current tenant within 30 DAYS** of execution or assignment of the management agreement; **transfer by the
> previous firm within 60 DAYS**; the new firm **verifies each deposit against the amount in the current
> lease and discloses any discrepancy**; and the tenant is **informed in writing if the owner is holding
> the deposit.**
>
> **Rule 5.7.A** — property management money is deposited **no later than FIVE BUSINESS DAYS** following
> receipt or mutual execution of a lease, **whichever is later**, where **Rule 5.7.B** gives all other money
> **three.**
>
> **Rule 5.14.B** — *"**No ledger may ever be allowed to have a negative cash balance.**"*
>
> **And nothing about the tenancies themselves is stated in this build.** **C.R.S. § 38-12-101 et seq. was
> NOT read**, so this course states **no deposit limit, return period, notice period, entry requirement,
> habitability standard or eviction procedure.** Those come from the statute, the leases, and counsel.

## F. The three problems from prepared contracts

The Commission requires that **three problems shall be using samples of prepared contracts.** In those
three the student is given **the contract itself** and works from it, rather than from a list of figures.

**What changes when the source is a contract:**

1. **The student must find the figures**, not receive them. Price, earnest money and its holder, the
   financing structure, the closing and possession dates, and every cost allocation are **in the document**.
2. **The student must notice what the contract does NOT say.** A cost the contract does not allocate is a
   **non-contractual fee** (Module 03 Part A.2) and needs an answer before closing.
3. **The student must notice inconsistency.** Dates out of sequence, a figure that appears twice
   differently, a contingency with no consequence.
4. **The student must resist closing to something other than the contract.** ***"Close to contract or amend
   contract in writing."***

> **A gate stated on this module's face.** **NO Commission-approved form was obtained, read, or reproduced
> by this project**, and **this course reproduces no contract.** The three prepared-contract problems
> require **samples of Colorado Commission-approved contracts**, obtained from the Division's website as
> **Rule 7.1.A** directs.
>
> **Building those three problems on the current forms is a submission gate**, and it is recorded as one in
> the course engine alongside the Contracts and Regulations course's form requirements.

## G. What a completed problem must show

| Check | What is looked for |
|---|---|
| **Every item placed** | Right party, right column, right sign |
| **Every proration correct** | Daily rate, day count, and **direction** — prepaid or in arrears |
| **Prorations sum to the whole** | Each party's share, added, equals the full amount |
| **Each party settles to one figure** | Cash from the buyer; cash to the seller |
| **In equals out** | The proof table balances to the cent |
| **Nothing unsupported** | Every charge traces to the contract or a written amendment |
| **Non-contractual items identified** | Named, and resolved before closing |
| **Nothing invented** | No rate, convention, fee or requirement supplied from memory or from another state |

**A problem that balances but carries a charge the contract does not support is not correct**, and that is
the point of Step 7. **Rule 6.19.A** requires an **accurate, complete and detailed** closing statement
**signed by the broker**; **Rule 6.19.B** makes a broker who prepares the documents responsible for their
**accuracy and completeness**; and **Rule 6.19.E** forbids **disbursing or authorizing disbursement** before
the funds are received and available.
